# Data Matrix Scanner

Android-приложение для пакетного сканирования маркировочных Data Matrix. Работает локально и не требует сервера.

## Что уже реализовано

- распознавание только Data Matrix через ZXing-C++ 3.1.1;
- постоянная мини-камера с центральным crop, размерами 348/174 dp по тапу без перезапуска camera pipeline и отдельной fullscreen-кнопкой;
- быстрые вкладки Активных, Архива и Корзины прямо в toolbar;
- счётчик реально активных записей текущего набора, голубая подсветка его строк, зелёные рамки активных кодов и жёлтые рамки дублей из архива;
- счётчик и кнопка «Следующий набор» поверх обычного preview камеры;
- быстрая камера с периодическим усиленным проходом для трудных кодов;
- сохранение фотографии из полноэкранной камеры в Галерею;
- автоматическое сохранение кадра первого распознавания во внутреннюю БД и просмотр с безопасной внешней рамкой;
- многопроходное восстановление Data Matrix из фотографии с отдельным списком «Принять/Удалить»;
- SQLite-база с `raw bytes`, SHA-256 и уникальным BLOB-ограничением;
- одна физическая запись на код, восстановление дублей из архива/корзины;
- append-only журнал событий;
- активные, архив, корзина, массовый выбор и рабочая отметка «Отсканировано»;
- fullscreen-просмотр с динамическим pager после архивирования, масштабированием/перемещением сохранённого кадра и размерами Data Matrix 95/190/340 dp;
- автоматическая сборка APK в GitHub Actions.

## Важное ограничение GS1

Исходные decoded bytes, GS1 content type и symbology identifier сохраняются отдельно. Регенерация выполняется в бинарно-безопасной кодировке ISO-8859-1 с GS1-флагом и quiet zone, но эквивалентность конкретной российской табачной маркировки необходимо подтвердить реальным повторным сканированием и аппаратным сканером Эвотора до производственного использования.
